# bgm-storage
QuestNotes用BGM保管庫/プレイヤーのゲーム体験を引き上げる為、高音質を保持する為使用します。

# QuestNotes BGM Project: AmberTeaRoom

このリポジトリは、オンラインRPG『QuestNotes』内で公開するボード
「大きなノルジャン猫がいる秋のカフェ(AmberTeaRoom)」で使用するBGM資産を管理するためのものです。
プレイヤーのゲーム体験と音質を損なわないよう、外部ストレージとして活用しています。

## 🔗 URLテンプレート
QuestNotesのBGM設定欄に貼り付けるURLのひな形です。
`https://raw.githubusercontent.com/himaponn2525/bgm-storage/main/ファイル名.mp3`

## ⚖️ クレジット・著作権情報
本プロジェクトのBGMは、以下の作曲家様の規約に基づき使用させていただいております。
AI生成作品は一切使用しておりません。

### 🎸 鷹尾まさき (Takao Masaki) 様
マスターコメント「背景としながらもありきたりにはならない劇伴を目指されているクリエイター様です。音選びが気持ちよく、長時間聴いていても疲れない曲が素晴らしいです」
- **公式サイト:** [https://takao-masaki.com/](https://takao-masaki.com/)
- **楽曲配布元:** [DOVA-SYNDROME (鷹尾まさき様ページ)](https://dova-s.jp/creator/detail/62)
- **利用規約:** [DOVA-SYNDROME使用許諾](https://dova-s.jp/contents/terms)

### 📝 利用上の備忘録（自分用）

- QuestNotes内では、必ずクレジット表記（例 作曲：鷹尾まさき）を併記すること。

## クレジット・著作権情報
本プロジェクトでは、AI生成作品を避け、人間による創作を尊重するため、
信頼できる作曲家様の楽曲を、各配信サイト（DOVA-SYNDROME等）の利用規約に基づき使用させていただいております。
著作権は各作曲家様に帰属します。
> ※既存のAI生成を使用して創作されている他クリエイター様を批判する意図はありません。
> あくまで本プロジェクトにおける、創作に対しての一個人のスタンス表明となります。
