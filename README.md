# bgm-storage
QuestNotes用BGM保管庫/プレイヤーのゲーム体験を引き上げる為、高音質を保持する為使用します。

# QuestNotes BGM Project: AmberTeaRoom

このリポジトリは、オンラインRPG『QuestNotes』内で公開するボード
「大きなノルジャン猫がいる秋のカフェ(AmberTeaRoom)」で使用するBGM資産を管理するためのものです。
プレイヤーのゲーム体験と音質を損なわないよう、外部ストレージとして活用しています。

## 🔗 URLテンプレート
QuestNotesのBGM設定欄に貼り付けるURLのひな形です。
`https://raw.githubusercontent.com/himaponn2525/bgm-storage/main/ファイル名.mp3`

## クレジット・著作権情報
本プロジェクトでは、AI生成作品を避け、人間による創作を尊重するため、
信頼できる作曲家様の楽曲を、各配信サイト（DOVA-SYNDROME等）の利用規約に基づき使用させていただいております。
著作権は各作曲家様に帰属します。
